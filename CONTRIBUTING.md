# Contributing to Chronolox CLI

This repository manages binary release verification, platform builds, checksums, and signing key distribution for Chronolox CLI.

## How to Contribute

- **Platform Testing:** Verify `chronolox-cli` on untested distributions or hardware configurations.
- **Verification Tooling:** Propose improvements to checksum verification scripts or shell integration.
- **Reporting Issues:**
  - For suspected corrupted archives or checksum discrepancies, open an [issue](https://github.com/Chronolox/cli/issues).
  - For security vulnerabilities, do NOT open a public issue. Follow [SECURITY.md](./SECURITY.md) and email `security@chronolox.com`.
